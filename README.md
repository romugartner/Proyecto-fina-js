# Proyecto Final - Simulador de Compra

Aplicación web interactiva desarrollada con HTML, CSS y JavaScript.

Requisitos:

- Manipulación del DOM y eventos, sin `prompt`, `alert` ni `confirm` nativos.
- Catálogo de productos almacenado en `modulo_08/productos.json` y consumido mediante `fetch`.
- Funciones de orden superior: `forEach`, `filter`, `find` y `reduce`.
- Persistencia del carrito mediante `localStorage`.
- Operadores avanzados: ternario, `||`, spread y destructuring.
- Asincronismo con `async/await` y manejo `try/catch/finally`.
- SweetAlert2 para mensajes y confirmaciones.
- Circuito completo: catálogo, búsqueda, ordenamiento, carrito, cantidades, eliminación, vaciado y finalización de compra.
- Validación de stock al agregar y modificar cantidades.

Ejecutar:

Abrir `proyecto_final_js/index.html` usando un servidor local, por ejemplo Live Server de Visual Studio Code, porque `fetch()` requiere servir los archivos mediante HTTP.
